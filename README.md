# Futuristic 3D TikTok Shop Farm

Glam's futuristic 3D TikTok Shop agent farm - a showcase page in TikTok colors (black, cyan #25F4EE, pink #FE2C55) with a tilting 3D phone hero, seven clickable agent mission cards, an animated launch sequence, the Run Board, Farm Laws, and the Live Games menu.

**Live page:** https://nakeymasi-coder.github.io/futuristic-3d-tiktok-shop-farm/

## The 7 agents

1. Pinterest Scout
2. TikTok Shop Agent
3. Story Agent
4. Muse Video Agent
5. Director QC
6. Caption & Post
7. TikTok Live Game Agent (LIVE ONLY) - watches Glam's TikTok Live chat, pulls the real people engaging (recent commenters, Top 10 Engagers), and builds a live game from those people: Names Wheel, Number Wheel 1 to 200, Top 10 Engagers Wheel, Top Engager Showdown, Trivia Pop, Last One Standing, Mystery Pumpkin Pick, Secret Word Drop, Closest Guess, Head-to-Head.

## Files

- `index.html` - the whole farm, one self-contained page
- `manifest.webmanifest` - install manifest (name, icons, colors)
- `icon-512.png`, `icon-192.png`, `apple-touch-icon.png`, `favicon-32.png` - the farm's icon set

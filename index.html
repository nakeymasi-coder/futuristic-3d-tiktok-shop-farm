03

Live Games — Agent A-09’s Menu

Agent A-09 works LIVE ONLY. When Glam goes live on TikTok, it watches her live chat for the window she picks — the last 20 minutes is standard — pulls the real people engaging (recent commenters and her Top 10 Engagers), and builds one of these games from those people for her to play on the live. Shares, taps, likes and gifts count only when TikTok actually shows them: anything it can’t see is marked NOT VISIBLE, and a pull that stops early is labeled PARTIAL with its times. No invented names, no invented numbers — ever.

GAME 01

Names Wheel

Everybody who commented in the window goes on the wheel. Glam spins it on the live and the name it lands on wins.

GAME 02

Number Wheel 1 to 200

Viewers guess a number in the comments — Agent A-09 logs each name with their guess — then the 1-to-200 wheel spins for the winning number.

GAME 03

Top 10 Engagers Wheel

Only the Top 10 Engagers from the window earn a spot on this wheel. The hardest-working viewers play for the prize.

GAME 04

Top Engager Showdown

The top engagers face off in rounds, head to head, until one champion is left standing.

GAME 05

Trivia Pop

Agent A-09 writes a question about the live’s topic. The first right answer in the comments takes it.

GAME 06

Last One Standing

The wheel spins to eliminate one name at a time. The last name left on the wheel is the winner — pure suspense.

GAME 07

Mystery Pumpkin Pick

The winner picks a pumpkin and reveals the mystery prize hiding inside it. The prizes are stocked below — real ones, Glam-approved.

GAME 08

Secret Word Drop

Agent A-09 drops a secret word into the live. The first person to comment that exact word wins.

GAME 09

Closest Guess

Viewers guess a number in the comments. Closest guess without going over wins — no spin needed.

GAME 10

Head-to-Head

Two top engagers, one wheel, one spin. Winner takes it — the fastest showdown on the menu.

🎃 Mystery Pumpkin Pick — the prizes inside

These are the only prizes stocked in the pumpkins — the ones Glam approved. The pumpkin only shows the prize on the live: the real code or product goes to the winner after, and only after Glam approves the exact message.

Product-to-Post Workflow

The farm’s Product-to-Post lane for every TikTok Shop category — and the detail for steps 7 and 8 of the Run Order up top, not a separate order of its own. One product at a time, one image at a time, in this exact order. The sequence below is non-negotiable: nothing jumps ahead, ever.

RUN ORDER 7

Model photo

Pick the model photo by the casting law in the Farm Laws. The actual product photo goes in as the reference image, under the exact-product law.

RUN ORDER 7 · EDIT LOOP

Review + edit loop

Mila reviews the model photo until it’s approved. Never jump ahead — no script, no caption while the image is still being fixed.

RUN ORDER 8

Say “Next”

“Next” delivers all three at once: the Video Express clip prompts (C## format, Realistic Consistent Character workflow, the approved model photo and the real listing photo as the references) + the hook + the ready-to-post caption — all to the Farm Laws.
